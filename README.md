# 바로픽 배송 비즈니스 로직

**작성자: 윤서영 | 담당 파트: 배송**

바로픽 프로젝트의 배송 기능을 개발하기 위한 **사전 조사 및 비즈니스 로직 설계 문서**입니다.

B마트·배민커넥트의 실제 앱 화면, 서비스 안내 및 운영 사례를 참고해 라이더의 가입부터 배차, 상품 픽업, 배송 완료, 정산까지의 흐름을 정리했습니다. 정상 배송뿐 아니라 취소·지연·오배송·파손·회수 등 실제 운영에서 발생할 수 있는 상황과 처리 주체도 함께 다룹니다.

## 주요 정리 내용

- **배송 흐름:** 주문·포장 → 배차 요청·수락 → 픽업·인계 → 배송·전달 완료 → 정산
- **예외 처리:** 고객 부재, 주소 오류, 배차 지연, 주문 취소, 상품 누락·파손, 환불·재배송·회수
- **앱 간 연동:** 각 담당자가 요청·확인할 정보와 주문·배송·재고·결제·정산의 연결
- **구현 고려사항:** 동시 배차 수락, 중복 요청, 통신 장애, 이력 관리 및 처리 결과 복구

배송 비즈니스 로직 문서를 먼저 읽고, 연동 문서에서 데이터와 API 설계를 확인하는 순서를 권장합니다. 연동 문서는 **Java·Spring Boot·MySQL**을 기본 설계 예시로 사용하며, 구현 전 팀에서 합의해야 할 정책과 단계별 구현 순서도 포함합니다.
