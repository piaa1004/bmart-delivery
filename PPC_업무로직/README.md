# PPC 공통 비즈니스 로직 자료

첨부 요청의 마지막 지시인 “공통 피킹패킹 포함 PPC 비즈니스 로직”에 대한 산출물입니다.

## 파일

- [업무 로직 Markdown](PPC_공통비즈니스로직.md): 전체 업무 규칙·상태·예외·API·산정 근거.
- [읽기용 PDF](PPC_공통비즈니스로직.pdf): 같은 내용의 인쇄·열람용 문서.
- [편집용 Word](PPC_공통비즈니스로직.docx): 같은 내용의 편집 문서.
- [지점별 계산표 CSV](PPC_지점별_계산표.csv): Excel에서 열 수 있는 UTF-8 BOM 계산표.
- [계산 근거 JSON](PPC_계산근거.json): 원시 기대값·고정값·미확정값.
- [재계산 스크립트](PPC_계산.py): Python 3 표준 라이브러리만 사용. 실행 시 같은 폴더에 CSV·JSON 생성.
- [검증 결과](검증결과.md): 산술·문서·출처 검증 및 미완료 물리 검증의 구분.

## 적용 범위

목포 원본 MD·이미지는 제공되지 않았고 관련 저장소에도 없었습니다. 33평 용도, 랙 수, 적재량, 생산성, 필요 인원, 실제 도면은 확정하지 않았습니다. 공통 상태·프로세스·API는 구현 제안입니다. 제공 수치 기반의 5개 지점 면적·SKU·수요는 재계산했습니다.

폴더 전체를 ZIP으로 내려받거나 필요한 파일만 다운로드할 수 있습니다. 기존 목포 원본이나 배송 문서를 변경하지 않고 별도 폴더로 추가했습니다. 이 자료는 실제 B마트 공식 운영 규정이 아닙니다.
